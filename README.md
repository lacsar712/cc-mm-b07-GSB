# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

正常行可以**双人确认后锁死**：检查员发起锁定申请，系统给出一次性确认口令；必须由旁观账号在另一会话输入该口令后才真正锁死。锁死后禁止改正浓度，总表仍可见但标记「已锁」。旁观账号不能发起锁定，只能确认。报警行（≥1%）不允许锁定。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可改正浓度、可发起锁定申请 |
| viewer | view123456 | 只能看、只能输入口令确认锁定 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 对东翼-12 点「申请锁定」，页面显示 6 位确认口令；该行在两个窗口都标记「待确认」。
5. 用 viewer 在另一会话输入口令确认，该行标记「已锁（确认人 viewer）」。
6. gasman 再对该行改正浓度应被拒绝（接口返回 409，该行浓度不变）。
7. 回风巷等报警行不出现锁定入口，直接调接口也会被拒绝。
