# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、改正浓度、发起锁定申请 |
| viewer | view123456 | 只能看，只能凭确认口令确认锁定 |

确认口令（旁观账号确认锁定时输入）：`810226`，可用环境变量 `LOCK_CODE` 覆盖。

## 锁定（双人确认）

正常行可以被锁死，流程必须两人、两个会话完成：

1. 检查员（gasman）对**正常行**点「申请锁定」，行进入「待旁观确认」，此时还没锁。
2. 另一会话用旁观账号（viewer）登录，页面顶部出现待确认列表，输入确认口令 `810226` 点「确认锁定」。
3. 确认后该行标记 **🔒 已锁**，默认总表仍可见。
4. 已锁行禁止改正浓度（接口返回 409，前端在行内提示），也不能再次发起锁定。

约束：

- 旁观账号不能发起锁定（403），检查员不能自己确认（403），口令错误拒绝（403）。
- **报警行不允许锁**（409）；改正后浓度升到报警线的行同样不可锁。
- 每一行同时只允许有一个待确认申请。
- 锁定、申请、确认、改正都会通过网页套接字实时推到所有已打开的页面。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 双人锁定：gasman 在东翼-12 行点「申请锁定」，行显示「待旁观确认」；用 viewer 在另一窗口登录，顶部待确认列表输入口令 `810226` 确认；该行变为 **🔒 已锁**，两个窗口同步刷新。
5. 已锁后在 gasman 窗口对东翼-12 改正浓度，被拒绝（提示「该行已锁定，禁止改正浓度」）。
6. 对照项：回风巷（报警行）没有锁定入口；viewer 页面没有「申请锁定」按钮。
